## 🐉 Sobre el proyecto

**Dragon Radar Hub** es una aplicación web inspirada en el universo de *Dragon Ball Z* que combina mapas, multimedia y datos en tiempo real en una sola interfaz con estética **cyberpunk**. Puedes trazar rutas hacia las esferas del dragón en Popayán, reproducir efectos de sonido, leer PDFs y monitorear la actividad sísmica del planeta como si fuera un detector de Ki.

> 💡 **Nota:** el despliegue está en Render. Si la página lleva un rato sin visitas, la primera carga puede tardar unos segundos mientras el servidor "despierta" ⏳.

## 💻 Instalación local

<details>
<summary><b>👉 Haz clic para ver los pasos</b></summary>

<br>

**1. Clona el repositorio**

```bash
git clone https://github.com/angelcamayojm-wq/TU-REPOSITORIO.git
cd TU-REPOSITORIO
```

**2. Crea y activa un entorno virtual**

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate
```

**3. Instala las dependencias**

```bash
pip install -r requirements.txt
```

**4. Aplica las migraciones y arranca el servidor**

```bash
python manage.py migrate
python manage.py runserver
```

**5. Abre en el navegador** 👉 `http://127.0.0.1:8000/`

</details>
